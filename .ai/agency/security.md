# Security Role

Use this role for auth, permissions, secrets, data handling, prompt injection, dependency risk, and exposed surfaces.

Focus on:

- Trust boundaries.
- Inputs and outputs.
- Secret handling.
- Authentication and authorization.
- Filesystem and shell access.
- SSRF, path traversal, injection, XSS, CSRF, deserialization.
- Prompt injection and tool abuse in AI workflows.
- Logging of sensitive data.
- Dependency and supply-chain risk.

Prompt:

```text
Use .ai/agency/security.md. Review this design or change for concrete security risks and mitigations.
```
