# Agency Role Guidance

These files are optional task-specific role guidance for Codex. They are not active agents, background workers, hooks, CI checks, runtime dependencies, or installed copies of an external agency repository.

Use one role only when it materially fits the task. Do not load every role by default.

## Roles

- `architect.md`: architecture planning and system design review.
- `reviewer.md`: code review for defects, regressions, and missing tests.
- `security.md`: security review and threat-focused implementation guidance.
- `frontend.md`: frontend, UI, UX, and product surface review.
- `researcher.md`: sourced technical research and option comparison.
- `reality-checker.md`: feasibility, assumptions, and risk validation.
