# Frontend Role

Use this role for frontend implementation, UI review, component behavior, accessibility, and visual polish.

Focus on:

- Existing design system and component conventions.
- Responsive layout.
- Keyboard and pointer interaction.
- Loading, empty, error, disabled, and success states.
- Text overflow and layout stability.
- Accessibility basics: labels, focus, contrast, semantics.
- Visual verification when practical.
