# Impeccable UI Rules

Use this file only for frontend, UI, UX, visual design, and product surface work.

## Principles

- Prefer usable product screens over marketing pages.
- Match the existing design system before inventing new components.
- Keep operational tools dense, scannable, and predictable.
- Avoid decorative UI that does not improve comprehension or workflow.
- Use real product, data, or domain visuals when visuals are needed.
- Make controls familiar: icons for common actions, toggles for binary settings, sliders or inputs for numeric values, tabs for views, menus for option sets.
- Keep cards for repeated items, modals, and genuinely framed tools.
- Do not nest cards inside cards.
- Do not use oversized hero typography inside compact panels, dashboards, sidebars, or tools.
- Ensure text fits on mobile and desktop.
- Avoid one-note palettes dominated by a single hue family.
- Verify important screens with screenshots when possible.
