# Sprint Planning

## Current Sprint Theme

Runtime truth and release trust.

## Sprint Entry Criteria

- Task exists in [[Backlog]].
- Task links to an epic in [[Epic Index]].
- Task has acceptance criteria and definition of done.
- Related risk exists in [[Risk Register]] if risk is high or critical.

## Sprint Exit Criteria

- Code merged or intentionally deferred.
- Tests pass.
- Related vault notes updated.
- [[Audit Resolution Tracker]] status updated.

Related: [[Active Sprint]], [[Completed Tasks]], [[Weekly Progress]].
