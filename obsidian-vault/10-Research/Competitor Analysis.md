# Competitor Analysis

## Reference Apps

- Signal
- WhatsApp
- Discord
- Telegram

## UX Lessons To Apply

- Calls should have one obvious active surface.
- Voice and video call screens should share a suite model.
- Incoming calls need large clear answer/decline actions.
- Minimized video should be a movable PiP.
- Top call manager should be compact and safe-area aware.
- Unsupported controls should be hidden, not shown broken.
