# ADR-003 - Obsidian Vault As Source Of Truth

## Context

Knowledge was spread across source files, README, docs, plans, QA notes, diagnostics, and conversation history.

## Problem

Future work risks repeating decisions and losing context.

## Options

1. Keep documentation scattered.
2. Create a repo-local Obsidian vault.

## Decision

Create `obsidian-vault/` and treat it as the living source of truth.

## Consequences

- Every major feature, bug, blocker, decision, and workflow should be documented here.
- Code changes should update relevant vault notes.
- Future AI sessions should read [[Project Memory]] and [[AI Context]] first.
