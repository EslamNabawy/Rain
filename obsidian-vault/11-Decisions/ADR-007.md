# ADR-007 - Message Loading Uses Bounded Live Tail And Pagination

Last updated: 2026-06-03

## Context

Rain stores chat messages locally in Drift. The audit identifies index and pagination validation as production-readiness work.

## Problem

Full conversation streams can become expensive as histories grow. Chat UI should not depend on loading every message at once.

## Options

1. Keep full ordered conversation streams.
2. Load only pages and manually poll for new messages.
3. Use a bounded live tail for recent messages plus explicit older-page loading.

## Decision

Message loading uses a bounded live tail plus pagination for older messages.

## Consequences

- Initial chat load stays bounded.
- New messages remain live.
- Older messages load on demand.
- Unread/read behavior must be tested around selected/open chat state.
- Drift indexes become a prerequisite.
