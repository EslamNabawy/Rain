# ADR-001 - Firebase Is Signaling Only

## Context

Rain is a peer-to-peer app using WebRTC for chat, files, voice, and video.

## Problem

Users and contributors can confuse Firebase signaling with media transport.

## Options

1. Send media through Firebase.
2. Use Firebase for signaling only and WebRTC for media/data.

## Decision

Firebase is used for auth, presence, friendships, signaling, call rooms, locks, candidates, and update policy. WebRTC carries chat data, file bytes, voice, and video.

## Consequences

- Firebase failures can stop setup but do not carry media packets.
- WebRTC NAT/TURN/ICE problems must be diagnosed separately.
- Firebase cost is tied to signaling and presence, not media bandwidth.
