# Settings

## Purpose

Allow users to manage app behavior without exposing broken or fake controls.

## Current Settings Areas

- Profile display name and gender.
- Microphone selection.
- Camera selection.
- Call audio/video processing toggles.
- Sound and notification behavior.
- Connection request behavior.
- About Rain and update status.

## Product Rules

- Device-specific controls must be based on actual device capability.
- Windows must not show fake Android speakerphone behavior.
- Camera flip only appears when multiple real cameras exist.
- Settings changes must persist and reload safely.
