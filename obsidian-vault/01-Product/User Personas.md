# User Personas

## Private Pair

Two users who already know each other and need direct private chat, files, and calls.

Needs:

- simple sign in
- visible online/connection state
- reliable chat and calls
- direct explanation when peer is offline or busy

## Device Tester

A developer/tester installing v7a, v8/v9, and Windows artifacts often.

Needs:

- direct release downloads
- clear version and update status
- diagnostics export
- fast reproduction loops

## Low-End Android User

User on ARMv7 or low-memory Android device.

Needs:

- no heavy animations
- smooth chat scrolling
- predictable calls
- small APK
