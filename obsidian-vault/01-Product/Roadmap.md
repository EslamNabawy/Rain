# Roadmap

## Phase 1 - Reliability Recovery

- Fix call lease and false busy behavior.
- Split call phases so signaling, media, permissions, and locks are distinct.
- Fix update validation and prompt behavior.
- Harden presence expiration and app-close handling.

## Phase 2 - Performance Foundation

- Add Drift indexes.
- Add message pagination.
- Rework file transfer streaming.
- Keep low-power rendering paths for ARMv7.

## Phase 3 - Production Gates

- Firebase emulator rule coverage.
- Android and Windows release gate parity.
- Diagnostics privacy hardening.
- Local Android QA harness smoke test.

## Phase 4 - Feature Expansion

- Closed-app push notifications.
- Better background behavior.
- Optional video polish and device-specific routing.
