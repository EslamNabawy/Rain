# CI-CD Roadmap

## Problems

- Multiple workflows duplicate validation logic.
- Some release gates are stricter than local Melos scripts.
- Firebase function jobs can conflict with Spark/free-tier direction.

## Target

- Reusable validation workflow.
- Reusable release build workflow.
- Shared Firebase validation job.
- Documentation vault check in CI.
